# گذر — پروژهٔ اندروید

این پروژه فایل `index.html` را داخل یک برنامهٔ اندرویدی با WebView قرار می‌دهد.

## ساخت APK با GitHub Actions
1. محتوای پوشهٔ `gozar-android` را در ریشهٔ مخزن GitHub خود آپلود کنید؛ پوشهٔ `.github/workflows/build-apk.yml` هم باید حفظ شود.
2. به زبانهٔ **Actions** بروید و Workflow با نام **Build Android APK** را باز کنید.
3. برای اجرای دستی، روی **Run workflow** بزنید؛ یا پس از Push روی شاخهٔ `main` یا `master`، اجرای خودکار را بررسی کنید.
4. پس از سبز شدن همهٔ مراحل، پایین صفحهٔ اجرای Workflow در بخش **Artifacts** روی `gozar-debug-apk` بزنید تا فایل ZIP حاوی `app-debug.apk` دانلود شود.

این Workflow نیازی به فایل `gradlew` ندارد؛ خودش Gradle 8.9 را دریافت می‌کند، بنابراین خطای `chmod: cannot access 'gradlew'` مربوط به Workflow قبلی رفع می‌شود.

## ساخت دستی در Android Studio
پروژه را باز کنید و با JDK 17 و Android SDK 35 گزینهٔ **Build → Build APK(s)** را اجرا کنید.

## مشخصات
- Application ID: `com.gozar.app`
- نام نمایشی: `گذر`
- حداقل اندروید: Android 7.0 (API 24)
- نسخه: `1.0.0`

## محدودیت مهم
این پروژه رابط HTML را بسته‌بندی می‌کند و **تونل VPN واقعی ندارد**. بررسی دسترسی به یک سرور با عبور دادن ترافیک گوشی از تونل VPN متفاوت است؛ در این پروژه موتور تونل‌زنی ادغام نشده است.
