# گذر — پروژه اندروید

این پروژه، فایل `index.html` شما را داخل یک برنامهٔ اندرویدی با WebView بسته‌بندی می‌کند و ساختار پروژه برای باز شدن در Android Studio آماده است.

## وضعیت فعلی
- رابط فارسی و امکانات پنل HTML داخل `app/src/main/assets/index.html` قرار دارد.
- تنظیمات و کانفیگ‌هایی که خود صفحه در `localStorage` نگه می‌دارد، در WebView حفظ می‌شوند.
- برای فونت‌ها و کتابخانه‌های CDN، اتصال اینترنت لازم است.
- **این نسخه تونل VPN واقعی ندارد.** دکمهٔ حلقه در HTML اصلی دسترسی سرور/پینگ را بررسی می‌کند؛ این کار به‌تنهایی ترافیک گوشی را از تونل عبور نمی‌دهد. در پروژه هیچ سرویس `VpnService` یا هستهٔ تونل‌زنی ادغام نشده است و برنامه ادعای اتصال VPN واقعی نمی‌کند.

## ساخت APK در Android Studio
1. Android Studio را نصب و باز کنید.
2. گزینهٔ **Open** را بزنید و پوشهٔ `gozar-android` را انتخاب کنید.
3. اجازه دهید Gradle Sync کامل شود؛ JDK 17 و Android SDK 35 لازم است.
4. از منوی **Build → Build APK(s)** خروجی را بسازید.
5. فایل خروجی معمولاً در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

## مشخصات
- Application ID: `com.gozar.app`
- نام نمایشی: `گذر`
- حداقل اندروید: Android 7.0 (API 24)
- نسخهٔ اولیه: `1.0.0`

## نکتهٔ حریم خصوصی
کانفیگ‌ها و لینک‌های اشتراک می‌توانند حاوی شناسه و رمز دسترسی باشند. فقط منابعی را وارد کنید که به آن‌ها اعتماد دارید و فایل‌های کانفیگ را عمومی منتشر نکنید.

## ساخت APK از طریق GitHub (بدون نصب Android Studio روی کامپیوتر)

1. فایل ZIP پروژه را استخراج و محتویات آن را در یک مخزن GitHub بارگذاری کنید.
2. در مخزن، زبانهٔ **Actions** را باز کنید و گردش‌کار **Build Android APK** را انتخاب کنید.
3. روی **Run workflow** بزنید (یا پس از push خودکار اجرا می‌شود).
4. بعد از اتمام موفق، در صفحهٔ اجرای workflow بخش **Artifacts**، فایل `gozar-debug-apk` را دانلود کنید.
5. ZIP دانلودشده را باز کنید؛ فایل `app-debug.apk` برنامهٔ قابل نصب است.

نکته: این APK نسخهٔ آزمایشی (debug) و فقط شامل رابط وب داخل اپ است. موتور VPN واقعی در این پروژه وجود ندارد.
